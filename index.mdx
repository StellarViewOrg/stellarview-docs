StellarView is an open-source suite for looking at what happens on Stellar. Use it in the browser, from the terminal, or run the indexer yourself and query the data over HTTP. Every part is licensed under Apache 2.0 and developed in the open.

<CardGroup cols={2}>
  <Card title="Explorer" icon="compass" href="/explorer/overview">
    Web explorer for ledgers, transactions, accounts, assets, the DEX, Soroban contracts, and `*.xlm` domains. Available in 9 languages.
  </Card>
  <Card title="TUI" icon="terminal" href="/tui/overview">
    Keyboard-driven explorer for the shell, with local bookmarks, notes, labels, and a live transaction feed.
  </Card>
  <Card title="Indexer" icon="database" href="/indexer/overview">
    Go service that ingests ledgers, operations, contract events, and token events into PostgreSQL and TimescaleDB.

  <Card title="API reference" icon="code" href="/api-reference/introduction">
    HTTP endpoints for network analytics, Soroban Domains, and contract source verification.
  </Card>

## How the pieces fit

The web explorer reads live data straight from Horizon and Stellar RPC, so it works without any StellarView backend. The indexer adds what those APIs can't answer on their own: history, network-wide analytics, domain lookups, and contract verification. The TUI can run against Stellar RPC alone, or pair with its own indexer for search, timelines, and holders.
