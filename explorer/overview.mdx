StellarView Explorer is the web app of the suite. It's live at [stellarview.acachete.xyz](https://stellarview.acachete.xyz), needs no account, and works on Public, Testnet, and Futurenet.

## Search

The search bar accepts any Stellar identifier and figures out what it is:

| Input | Example | Opens |
| --- | --- | --- |
| Account public key | `GA...` (56 characters) | Account page |
| Contract ID | `CA...` (56 characters) | Contract page |
| Transaction hash | 64 hex characters | Transaction page |
| Ledger sequence | `52000000` | Ledger page |
| Domain | `alice.xlm` | The account or contract it resolves to |
| Asset | `USDC-GA5Z...` (code, dash, issuer) | Asset page |

## Developer Mode

Toggle Developer Mode from the header to show the details most people don't need: raw XDR, fees in stroops, full operation parameters, and effect metadata. The setting is remembered in your browser.

## Languages

The explorer is translated into English, Spanish, Portuguese, French, German, Chinese, Japanese, Korean, and Italian. The locale is the first segment of the URL, so `/es/public/...` opens the Spanish interface.
