StellarView es una suite de código abierto para ver lo que ocurre en Stellar. Úsala en el navegador, desde la terminal, o ejecuta tú mismo el indexer y consulta los datos por HTTP. Todas las partes tienen licencia Apache 2.0 y se desarrollan de forma abierta.

## Cómo encajan las piezas

El explorador web lee datos en vivo directamente de Horizon y Stellar RPC, así que funciona sin ningún backend de StellarView. El indexer agrega lo que esas APIs no pueden responder por sí solas: historial, analíticas de toda la red, búsqueda de dominios y verificación de contratos. La TUI puede funcionar solo con Stellar RPC o combinarse con su propio indexer para búsqueda, líneas de tiempo y holders.
